在线游戏源想法完成记录

状态：已在 Playmesh 1.2.0+3 完成。
详细版本日志：docs/version/1.2.0.md
接口文档：docs/catalog-api.md

已完成接口：

1. GET /apps/list
   - 支持 size、page、s_name、s_tag、s_desc。
   - 返回 total、current、size 和完整 GameManifest data。
   - 名称、标签、描述搜索不区分大小写。
   - size 范围 1 至 100。

2. GET /apps/download?id=xxxxx
   - 下载只包含 main.json 和 app/ 的标准 Playmesh 游戏包。
   - 下载端继续经过原有完整安全校验后原子安装。

3. 鉴权
   - 设置页可持久化配置开关、端口和 Token。
   - Token 非空时两个接口都要求 Authorization: Bearer <token>。
   - Token 留空时不要求鉴权。

App 内能力：

- 设置页提供“分享本机游戏库”开关、端口、Token、局域网地址、二维码和复制配置。
- Catalog Gateway 默认端口 16668，与 Go Core、游戏分享和 Developer Gateway 独立。
- 在线游戏库位于现有游戏库内部，没有增加第二个首页游戏库入口。
- 可以保存多个 Host/Token 游戏源，每个源可启用、禁用、编辑、删除、扫码添加和二维码分享。
- 默认每个启用源获取 5 个，可配置；进入和搜索都并发请求全部启用源，再按游戏 ID 去重。
- 单个源失败时保留其他源结果。
- 游戏支持多选下载。
- 下载队列显示等待、进度、完成、停止和失败，可停止或删除任务。
- App 退出时先取消活动下载并等待队列收尾，不会在对象释放后继续刷新界面。
