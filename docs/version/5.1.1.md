## 升级原因与兼容性

5.1 build 37 之后的改动包含 WebView File System Access 兼容桥、持久玩家 ID、主会话
1 MiB 消息、完整 Authority RTT、1 MiB 流式上传分块、Authority 入口隔离、游戏包更新事务
和项目校验边界修复。App、Runtime 与 Go Core 都有实际实现变化，按兼容修复递增 PATCH；
两个 Flutter 可分发目标同时递增构建号。

会话创建请求新增可选 `playerId`。新 Core 仍允许旧调用方省略该字段，但旧 Core 的严格
解码器会拒绝新调用方发送的字段，因此 Core 协议从 `1.5.0` 升级到 `1.6.0`，防止主 App
把不兼容 Core 误判为同一协议。独立 Runtime 按设计保留跨兼容版本使用，不对 Core 健康响应
做精确协议版本锁定；其可用性由随底包同源构建的 Core、SDK 兼容区间和行为回归共同保证。

按本轮要求，Game SDK 与 App Bridge SDK 版本不变。生成物内容包含兼容修复，但未删除、
重命名或收窄既有公开接口。

需要单独记录的是：版本号虽然不变，SDK 生成物字节已经变化；其中 App bundle 增加的是
Web 标准 File System Access API 的宿主兼容层，而不是新的 `playmesh` 命名空间方法。Runtime
底包按下文哈希嵌入新文件，因此本轮导出链路不会混入旧 SDK；但任何只按 `4.3.0`/`3.5.0`
版本字符串长期缓存 SDK 的外部分发端，都必须在发布时同步替换文件并清缓存，否则可能继续
命中同版本旧字节。这是“SDK 版本不变”决策留下的发布约束。

## 用户与开发者变化

- Windows 与 Android 游戏可通过系统选择器打开、保存文件和选择目录。句柄支持读写、
  seek、truncate、目录枚举、删除、resolve 和同一条目判断；网页不接收原生路径或
  Android `content://` URI。
- 本机资料首次创建时生成并保存 `u_` 前缀 UUID v4；未重装或清理数据时，创建新会话继续
  使用同一玩家 ID。稳定 ID 不是凭据，Core 仍校验短期会话凭证。
- 主 Session WebSocket 和普通 Session JSON 请求上限提升到 1 MiB。超限 WebSocket 消息
  被逐条丢弃，不关闭主会话。
- Authority 延迟探针完整经过 Authority SDK 后原样返回；Core 不再伪造 pong 或时间戳，
  App SDK 在连续无响应后让旧延迟样本过期。
- RPC Stream 与 `StorageBucket.upload()` 的私有 `chunked-v1` 分块从 64 KiB 提升到
  1 MiB；512 MiB 单流上限和单分块在途背压不变。
- 非 Authority 页面请求 `main.json.authority.entry` 时只得到 JavaScript 类型空响应，
  不下载或执行权威逻辑。
- 同 ID 游戏更新只替换包拥有的 `app/`、清单、可选能力声明和图标；`data/`、`cache/`、
  `.playmesh/` 与其他非包根内容原位保留，并通过持久事务恢复中断。
- 项目校验不再以静态正则猜测 HTML/CSS/JavaScript 动态资源引用是否存在；清单入口、路径、
  UTF-8 和保留命名空间校验仍保留。

## 已知限制、发布与回滚

- 尚未执行 Windows/Android 系统文件选择器、覆盖写、目录树、取消和导航中断实机验收，
  也未执行两台设备、长时在线、接近 1 MiB 快照、大文件上传或公网 TURN 手工验收。
- 由于上述实机项目仍未完成，本次发布标记为 Pre-release，不能当作最新稳定正式发行；
  最新稳定正式发行仍是 `4.5.0+33`。
- 若 WebIDE 用于正式发布而不是本地开发包，必须执行 `webide-pipeline.mjs all`，不能把
  本轮 `dev-package` 写成 Flow 或正式全量门禁已经通过。
- SDK 版本号未变化但生成物哈希已变化；外部分发/CDN 若以版本字符串作为不可变缓存键，
  发布时必须原子替换四个 SDK 文件并主动失效旧缓存。Runtime 底包自身已由清单哈希保护。
- `mobile_scanner` 与 `speech_to_text` 仍有 Flutter Built-in Kotlin 未来兼容警告；当前
  构建成功，但后续 Flutter 强制迁移前必须升级或修复插件。
- 回滚 Runtime 时必须同时恢复三个固定底包、`resources/runtime/update.json` 与对应版本
  归档；回滚整个发行还需恢复 App 固定镜像/下载清单、App/Runtime/Core 版本常量和 SDK
  生成物，不能混用清单哈希。
