# Playmesh 1.5.0

发布日期：2026-07-21  
App 版本：`1.5.0+6`

## 组件版本

| 组件 | 升级前 | 升级后 |
| --- | --- | --- |
| Playmesh App | `1.4.0+5` | `1.5.0+6` |
| Game SDK | `1.3.0` | `1.4.0` |
| App Bridge SDK | `1.1.0` | `1.2.0` |
| Developer API / OpenAPI | `1.2.0` | `1.3.0` |
| Developer CLI | 无 | `1.0.0` |
| Go Core | `0.2.0` | `0.2.0` |
| Catalog API | `1.1.0` | `1.1.0` |

本版本新增保持主版本兼容的外部 IDE 开发、统一 SDK 生成与整包发布能力，因此 App、两套 SDK 和 Developer API 升级 `MINOR`，并首次发布 CLI `1.0.0`。Go Core、Catalog API 和 Core 协议没有改变。

## 外部 IDEA 开发

- 新增 Go CLI：`playmesh-cli to/get/push/dev/sdk`。`to` 直接接收并解析完整开发者工作区 URL，用户无需手工拆分 Base URL 和 token。
- `get` 保持包内 `app/` 为本地 `app/`，并在 `playmesh/sdk/` 安装目标 App 提供的两套 JavaScript SDK 与 `.d.ts`；两者分别镜像运行时 `/app/`、`/playmesh/`，供 IDEA 完整解析 JS/CSS/HTML 绝对路径。
- `push` 和 `dev` 只上传 `main.json`、`capabilities.json`、`app/`，并完全排除本地 `playmesh/`。打包前从 SDK 文件读取真实版本并覆盖 `main.json.sdkVersion/appSdkVersion`。
- `dev` 原子提交后启动或重启当前项目。如果其他项目正在运行，先关闭它再切换；SSE 日志跟随到对应 WebView 退出。终止 CLI 只分离日志，不结束 App 中的游戏。
- Developer Gateway 新增 SDK bundle、当前全局运行、项目包导出和整包导入端点；CLI 上传继续复用应用正式游戏包导入器，不另建第二套包校验规则。
- CLI 正式二进制统一命名为 `playmesh-cli`（Windows 为 `playmesh-cli.exe`），并跟随 Windows、Linux、macOS App 构建；产物位于桌面 App/Go Core 同级运行目录，Android/iOS 不携带。

## SDK 单一来源

- 手写源统一为 `assets/playmesh-library/sdk-src/playmesh.ts` 和 `playmesh-app.ts`，版本常量写在对应源文件内。
- `tool/generate_sdk.mjs`/`generate_sdk.ps1` 生成 `.js`、`.d.ts`、SDK Manifest/Schema 版本、默认模板版本和 Dart 版本常量；Android/Windows 正式构建脚本已在构建前执行生成器。
- App 运行注入、网页工作区补全、CLI 下载和 IDEA 提示统一读取生成目录，消除运行代码与类型提示不同步的问题。
- 生成的 `.d.ts` 包含完整中文 JSDoc，并修正 `sync.submitState`、Authority 控制器和生命周期回调等精确签名；IDEA 可直接显示中文成员说明、参数、返回值与限制。

## 游戏包更新语义

- 应用导入包时以 `main.json.id` 判断新增或更新。
- 同 ID 更新只原子替换 `main.json`、`capabilities.json` 和 `app/`；未包含新的 `capabilities.json` 时删除旧声明。
- `data/`、`cache/` 以及其他非发布内容不移动、不覆盖；更新失败回滚三个发布项。
- 安装目录不再创建实体 `.playmesh/` 元数据目录。CLI 项目改用无点前缀的 `playmesh/sdk/` 镜像公共 URL 空间，且永不进入上传包。
- 测试开发阶段统一把游戏包 `app/` 暴露为 `/app/...`；旧 `/game/...` 路径不再兼容。默认模板、校验器、App WebView、浏览器分享、SDK 契约和 AI 提示词同步使用新路径，版本仍保持 `1.5.0` 系列。

## 游戏详情体验

- 游戏详情页将版本和稳定 ID 分开显示；点击带复制图标的游戏 ID 会写入系统剪贴板，并显示成功或失败反馈。
- 从详情页导出的包统一建议命名为 `{游戏名称}-v{版本}.zip`，例如 `欢乐派对-v1.2.3.zip`。平台会替换文件名非法字符、去除尾部点和空格并限制名称长度，Android 分享与桌面保存使用同一规则。
