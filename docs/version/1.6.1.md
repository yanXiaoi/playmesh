# Playmesh 1.6.1

发布日期：2026-07-21  
App 版本：`1.6.1+8`

## 组件版本

| 组件 | 升级前 | 升级后 |
| --- | --- | --- |
| Playmesh App | `1.6.0+7` | `1.6.1+8` |
| Game SDK | `1.4.1` | `1.4.2` |
| App Bridge SDK | `1.2.1` | `1.2.1` |
| Developer API / OpenAPI | `1.4.0` | `1.4.0` |
| Developer CLI | `1.1.0` | `1.1.0` |

## 修复

- Android/iOS `webview_flutter` 宿主不再把 Game SDK Bridge 的 JSON 回包二次编码为 JavaScript 字符串，而是与 Windows 一致地作为对象传给 `playmesh.__receive`。
- Game SDK 接收端同时兼容对象与 JSON 字符串回包，旧宿主即使仍传字符串也能完成 `sdk.ready`。
- 新增回归验证，使用字符串形式的 `sdk.bootstrap` 完成 `playmesh.ready`，覆盖 Android 上 15 秒后报 `Playmesh Bridge 请求超时: sdk.ready` 的故障。

本次没有改变公开 SDK 类型、App Bridge SDK、Developer API、CLI、Go Core 或数据格式，属于兼容补丁升级。

## 构建

本版本按需求只构建 Android Release APK，不重建 Windows。构建与签名验证记录见 `docs/verification/playmesh-1.6.1-android-build-2026-07-21.md`。
