# Playmesh 1.8.0

## 发布信息

- 日期：2026-07-24
- App：`1.8.0+13`
- 状态：内部开发构建

## 组件版本

| 组件 | 变更前 | 当前 | 原因 |
| --- | --- | --- | --- |
| Playmesh App | `1.7.0+12` | `1.8.0+13` | 角色化全屏方向、发布元数据、详情展示与上传历史 |
| Go Core | `0.3.0` | `0.3.0` | 无线级协议变化 |
| Core 协议 | `1.1.0` | `1.1.0` | 无字段变化 |

| Developer CLI | `1.2.0` | `1.3.0` | 创建流程支持控制器方向与独立能力 |

## 主要变化

- 单屏多人分别声明并应用主画面与控制器方向。
- 普通浏览器不显示入场全屏提示层，由 SDK 无弹窗尽力自动全屏，失败后仍可从悬浮工具栏手动重试。
- 主画面和控制器分别声明并获得平台能力。
- 上传时由 App 注入不可编辑的作者和最后上传时间；详情页按本地时区紧凑展示。
- Agent/CLI 整包发布接入可恢复的开发者本地历史。
- Manifest、能力 Schema、OpenAPI、模板、提示词、SDK 生成物、CLI 和开发文档同步升级。

## 兼容性

- 当前开发线只接受含 `author`、`lastModifiedAt` 的当前 Manifest。
- 单屏多人必须同时提供 `controllerOrientation`；`controllerRequired` 仅在该模式合法。
- SDK 静态分发 URL 仍为 `/playmesh/sdk/v1/`，语义版本由文件内容和 Manifest 字段声明。

完整回归、构建产物、签名状态和 SHA-256 见 `docs/verification/playmesh-1.8.0-orientation-metadata-build-2026-07-24.md`。
