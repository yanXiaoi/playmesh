# Playmesh 1.6.0

发布日期：2026-07-21  
App 版本：`1.6.0+7`

## 组件版本

| 组件 | 升级前 | 升级后 |
| --- | --- | --- |
| Playmesh App | `1.5.0+6` | `1.6.0+7` |
| Game SDK | `1.4.0` | `1.4.1` |
| App Bridge SDK | `1.2.0` | `1.2.1` |
| Developer API / OpenAPI | `1.3.0` | `1.4.0` |
| Developer CLI | `1.0.0` | `1.1.0` |
| Go Core | `0.2.0` | `0.2.0` |
| Catalog API | `1.1.0` | `1.1.0` |
| Core 协议 | `1.0.0` | `1.0.0` |

App 新增兼容的 WebView 宿主日志与单机运行能力，因此升级 `MINOR` 并递增构建号。Game SDK 与 App Bridge SDK 的公开方法不变，注入诊断、请求超时和单机握手属于兼容修复，因此递增 `PATCH`。Developer API 新增日志事件归属和过滤字段，Developer CLI 新增版本命令及日志轮询兜底，均为兼容新增，递增 `MINOR`。Go Core、Catalog API 与 Core 协议未改变。

## WebView 本机日志

- App WebView 在宿主层捕获当前设备页面的 `console.log/info/warn/error/debug`、资源加载错误、未捕获异常和 Promise 拒绝，不依赖 Game SDK 上报，也不跨设备转发。
- 每次启动、重试、重新开始或刷新游戏前清空旧缓存；本次运行最多保留 500 条，并用稳定 `eventId`、`projectId` 和 `runId` 标记归属。
- App SDK 与 Game SDK 分别输出注入成功和 Bridge 就绪日志。Bridge 请求超过 15 秒会 reject 并产生明确诊断，不再永久等待。
- App WebView 网关会在入口缺少标签时按 App SDK、Game SDK 顺序补齐双 SDK。

## 单机 Game SDK Bridge

- 单机 App 游戏不再绕过 Game SDK 宿主层；新的本地 Bridge 响应 `sdk.ready`，返回无多人 Session 的 bootstrap。
- 单机 `playmesh.storage`、性能可见性、FPS/延迟上报和生命周期命令使用同一 Bridge；退出和重新开始前完成本地存储落盘。
- 旧行为会在用户完成能力确认后把 `sdk.ready` 发给空的多人 Bridge，导致 `await playmesh.ready` 永久等待；本版本已覆盖该回归测试。

## Developer CLI 与日志通道

- `playmesh-cli dev` 先回放当前 run 的缓存，再并行使用 SSE 和 500 ms 日志轮询；SSE 首字节被缓冲或连接中断时仍能输出日志。
- 日志按 `projectId + runId` 过滤并按 `eventId` 去重，WebView 退出后轮询运行状态并结束；旧页面退出不能停止同项目的新 run。
- CLI `1.1.0` 支持 `--version`、`-v` 和 `version`，且 `dev` 启动时主动输出版本。User-Agent 与版本常量使用同一来源。
- Developer SSE 响应关闭输出缓冲。`GET /dev/api/logs` 增加 `projectId`、`runId` 查询过滤，日志事件增加对应归属和稳定事件 ID。

## SDK、AI 提示词与文档单一来源

- `sdk-src/playmesh.ts` 与 `sdk-src/playmesh-app.ts` 继续作为唯一手写 SDK 源，生成运行 JS、完整中文 `.d.ts`、Manifest、Schema、默认模板版本和 Dart 常量。
- 对话 AI 与 Agent 项目提示词现在嵌入同次生成的完整 `playmesh.d.ts` 和 `playmesh-app.d.ts`，并明确以其方法、参数、返回值、类型、版本和中文 JSDoc 为唯一接口事实源。
- 提示词中的 SDK 列表只保留运行边界摘要；生成器同步摘要中的 Game SDK 版本，避免手写版本漂移。

## 兼容性、升级与回滚

- 游戏包结构、公开 `/app/` 与 `/playmesh/sdk/v1/` 地址不变。当前项目需要把 `main.json.sdkVersion` 更新为 `1.4.1`，把 `appSdkVersion` 更新为 `1.2.1`；CLI `get/sdk/push/dev` 会使用目标 App 的同源 SDK 自动对齐。
- 已安装游戏数据格式不变，无需清理 `data/` 或 `cache/`。
- 回滚 App 时应同时回滚两套 SDK 生成产物、Developer API 契约和桌面 CLI，避免旧 App 携带新版本声明。
- Android 未配置生产签名时只能生成 Debug 证书签名的内部 Release APK，不能作为商店正式包。

## 关键入口

- WebView 日志：`lib/core/developer/webview_console_capture.dart`
- 单机 Bridge：`lib/core/game_sdk/standalone_game_runtime_bridge.dart`
- Game 页面运行绑定：`lib/features/game/game_page.dart`
- Developer 日志 API：`lib/core/developer/developer_web_gateway_io.dart`
- CLI 日志与版本：`dev-cli/commands.go`、`dev-cli/main.go`
- SDK 与 AI 提示生成：`tool/generate_sdk.mjs`、`assets/playmesh-library/sdk-src/`
