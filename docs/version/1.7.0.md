## Binary Channel

- 原有 JSON Session WebSocket 保持不变。SDK 在游戏首次调用 `playmesh.binary` 时按需建立第二条 Binary WebSocket；游戏代码不接触 URL、token、帧头或连接生命周期。
- 一条 Binary WebSocket 复用多个相互隔离的逻辑 Channel。Channel ID 同时作为本局加入令牌；只有 Authority 可以创建和关闭，创建后 Authority 自动加入。
- Channel 支持 `mode: "authority"` 与 `mode: "relay"`。`relay` 直接路由不透明字节；`authority` 把非 Authority 数据交给 Authority `onForward`，允许原样通过、替换为新 `Uint8Array` 或抛错拒绝。
- Authority 二进制身份固定为 `playmesh.binary.authorityPlayerId === "authority"`。Authority 与普通玩家都可用 `send(id, data)` 单发、`send([id...], data)` 一帧多发、`send(data)` 广播给除自己外的 Channel 在线成员；Authority 也可以主动推送数据。
- `send` 可靠排队；`sendLatest(id 或 id[], data)` 按规范化目标集只保留尚未发送或尚未开始审核的最新帧，快捷重载 `sendLatest(data)` 对广播提供相同能力。接收端统一使用 `onMessage`，通过 `context.delivery` 区分 `queued/latest`。
- 多目标 payload 只上传一次并由 Core 扇出；`authority` 模式中每帧只审核一次，`onForward` 上下文即使单发也始终提供 `targetPlayerIds` 数组。
- Authority JavaScript 处理器一旦开始执行，旧、新审核都继续运行，Core 接受并执行两者各自的结果，不以较新的请求取消已经开始的旧结果。
- Authority 关闭 Channel、Authority Binary 断开、主 Session 退出或游戏结束时，Core 释放该游戏创建的全部 Channel。

局域网防失控边界：

- 单帧：4 MiB
- 单连接：2000 帧/秒、64 MiB/秒入站
- 单连接出站队列：32 MiB
- 每局 Channel：1024
- Authority 待审核：1024 项、128 MiB、15 秒超时

## Bucket JSON 与二进制文件

- JSON Bucket 当前写入 `packages/{gameId}/data/json/{bucket}.json`，只通过 `getData/setData/removeData/clearData` 访问。
- 新增 `StorageBucket.upload(file)`：直接发送原始文件流，不经过 JSON 或 Base64；单文件上限 256 MiB。
- 上传文件写入 `packages/{gameId}/data/data/{bucket}/{timestamp-ms}.{ext}`。平台以毫秒时间戳重命名，保留 1 至 16 位字母数字后缀，并返回 `/bucket/{bucket}/{file}`。
- 游戏运行期间仅把 `data/data` 映射到 `/bucket`。`data/json` 始终私有；网关不提供目录枚举，并拒绝跨 Bucket 与路径穿越。
- App WebView 与局域网浏览器均访问 Authority 主机的同一份数据。浏览器上传使用本局分享 token，GET 文件地址在本局运行期间保持同源可读。

## 兼容性

- Binary Channel 和 `upload(file)` 是兼容新增，现有 JSON 消息、Authority Service、同步与 Bucket key/value 调用不需要修改。
- JSON Bucket 地址直接采用 `data/json` 新契约；平台不读取、不迁移、也不删除旧的 `data/{bucket}.json`。需要旧数据时由游戏开发者自行处理。
- Game SDK 静态分发 URL 仍为 `/playmesh/sdk/v1/playmesh.js`，但 `main.json.sdkVersion` 必须使用当前 `2.1.0`。
- App Bridge SDK、能力插件协议、Developer API 与 CLI 协议未升级。

## 回滚与数据清理

- 回滚 App/Core 时不要让使用 Binary Channel 的游戏继续声明 Game SDK `2.1.0`。
- 回滚到旧 Bucket 路径的版本不会读取 `data/json`；两个路径不会自动互相复制。
- “清除游戏数据”删除当前游戏整个 `data/`，包括私有 JSON 与上传文件，操作不可恢复。
- 安装包与导出游戏包仍不包含 `data/` 或 `cache/`。
