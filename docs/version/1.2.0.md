# Playmesh 1.2.0 更新日志

## 发布信息

- 发布日期：2026-07-18
- App：`1.1.0+2` → `1.2.0+3`
- Catalog API：新增 `1.0.0`
- Go Core：保持 `0.2.0`
- Game SDK：保持 `1.2.0`
- App Bridge SDK、Developer API、Core 协议：保持 `1.0.0`

## 升级原因

本版本新增本机游戏源服务、在线多源游戏库和下载队列，属于 App 向后兼容的公开能力新增，因此 App 升级 `MINOR` 并递增构建号。Catalog API 首次发布为 `1.0.0`；游戏运行 SDK、Core 会话和 Developer API 没有变化，不跟随升级。

## 用户可见变化

- 设置页可开启“分享本机游戏库”，自定义端口和可选 Token，并通过地址、二维码或复制配置分享游戏源。
- 游戏库内新增唯一的在线游戏库入口，不在首页增加第二个游戏库入口。
- 在线游戏库可保存多个 Host/Token 源，每个源可单独启用、禁用、编辑、删除、扫码添加和分享。
- 默认并发从每个启用源获取 `5` 个游戏，可配置数量；名称、标签和描述搜索同样并发执行，最终按游戏 ID 去重展示。
- 在线游戏支持多选下载；下载队列显示进度和结果，并可停止或删除任务。

## API 与安全边界

- 新增 `GET /apps/list`，支持 `size`、`page`、`s_name`、`s_tag`、`s_desc`，返回完整 `GameManifest`。
- 新增 `GET /apps/download?id=...`，返回仅包含 `main.json` 和 `app/` 的 Playmesh 压缩包。
- Token 非空时使用 `Authorization: Bearer <token>`；Token 留空时不鉴权。
- Catalog Gateway 独立于 Go Core、游戏分享和 Developer Gateway，默认端口 `16668`，契约版本 `1.0.0`。
- 远程下载不能绕过既有包导入校验；临时文件在导入后删除，停止任务或 App 退出会取消活动请求。
