## Authority RPC 与本机存储

- `playmesh.main.rpc.request(path, data, options)` 可由会话中的客户端向 Authority 发起异步
  请求；只有 Authority 能通过 `onRequest(path, handler)` 注册处理器。处理器支持同步或
  异步返回，并提供请求 ID、发送玩家、当前会话和成员上下文。
- RPC 复用已认证的 Binary WebSocket，支持 JSON 兼容值、`Blob`、`File`、
  `ArrayBuffer` 与 `Uint8Array`。Go Core 校验身份、路径、并发、大小和超时，拒绝非
  Authority 伪造响应；请求/响应不再经过 JSON action 信封。
- `playmesh.app.storage.getBucket(name)` 提供当前设备独占的异步 JSON Bucket。原生 App
  按游戏隔离落盘，普通浏览器回退到当前源 `localStorage`；数据不上传 Authority、Core、
  Relay 或其他玩家。它与共享会话数据使用的 `playmesh.main.storage` 具有不同所有权。
- 两项能力均在当前 Game SDK `4.1.0` / App Bridge SDK `3.3.0` 内兼容提供，本次不继续
  提升 SDK 版本号。

## 安装包导出与 Runtime

- 安装包导出改为“平台与底包 → 导出参数 → 生成安装包”三步向导，可逐步返回。需要下载
  或更新底包时必须明确选择资源源和已并发测速的线路；客户端只提交受校验 opaque ID，
  服务端仅下载所选线路，不做静默回退。
- 新增默认关闭的“自动同意能力授权”选项和可选内置中转服务器。点击入口先显示向导，
  本地状态、目标资源和中转列表按所在步骤异步加载，不再阻塞首屏弹窗。
- Runtime `1.0.1+4` 分享面板可在多条非回环 LAN 地址间切换二维码。主 App 与 Runtime
  通过 `packages/playmesh_ui` 复用只含 Playmesh 标识和进度指示的统一加载层。
- Runtime 更新清单和三个底包继续以 SHA-256 为唯一安装/更新判断依据；安装包生成仍执行
  目标下载、摘要校验、缓存、资源注入、加密与签名边界。

## 工作区、发布源与 Go Server

- 源代码工作区按当前资源源在 `localStorage` 记忆最近项目 ID；下次只在该项目仍存在时
  自动打开，否则展示项目选择器，不回退到服务端活动项目或列表首项。
- “上传到发布源”不再执行项目语义校验，也不返回验证报告或
  `package_validation_failed` 422；本地运行、安装包导出、重新导入和 AI 操作原有校验
  不受影响。Developer API / OpenAPI 因删除公开响应与错误语义升级到 `5.0.0`。
- Go Server 接收包不再绑定当前 SDK 版本或固定清单结构，并保留未知清单字段。默认扫描
  允许外部 URL、动态 `Function` 和嵌入内容；`app/` 内资源不再受扩展名白名单限制。
- ZIP 路径、压缩/解压容量、符号链接、基础清单元数据、入口非空 UTF-8 与 NUL 检查仍然
  保留。放宽内容扫描提高兼容性，也扩大了发布内容的主动代码能力；运营方必须继续只信任
  已审核来源，不能把“上传成功”解释为内容安全审核通过。
- App 与网页上传共享的服务端 IP 限流窗口由 30 秒缩短为 2 秒。

## 已知边界与回滚

- RPC 已覆盖编码、身份、超时、伪造响应和关闭清理自动化；跨 Android/Windows 真实设备
  的大 Blob/File 往返、网络切换与 Authority 离线仍需实机验收。
- Android、Windows 的安装包导出向导、系统保存/分享面板、自动授权开关和多网卡二维码
  仍应补充实机交互验收。自动能力授权默认关闭，不应在发行说明中描述为默认放宽权限。
- 回滚主应用时必须同时回滚 `pubspec.yaml`、发布简略日志、Developer API 版本、
  `resources/app/update.json`、两个固定镜像以及本版 GDevelop/Runtime 清单和制品。
