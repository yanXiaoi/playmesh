## 用户与开发者变化

- Android/iOS WebView 宿主消息在页面完成加载前进入顺序队列，修复 App bootstrap 回包过早执行后丢失、游戏永久停留在“正在连接体感”的问题；导航或投递失败时可安全重试。
- 开发者工作区“更多”菜单新增“能力测试”，测试项由统一能力注册表生成，可逐项或一次测试全部能力，显示通过、不可用、超时、失败或未注册 adapter。
- 新增 `GET /dev/api/capability-tests` 与 `POST /dev/api/capability-tests`。POST 可传 `codes` 与 `timeoutMs`；省略或传空 codes 时测试全部注册能力，传感器测试返回首个样本。
- 新建项目时可直接配置标签和能力；标签写入 `main.json.tags`，非空能力写入根目录 `capabilities.json`。
- 工作区对话框输入框、下拉框和文本域统一高度、行高与内边距，修复文字显示不完整。
- “获取项目提示词”和 Agent Base URL 选择正式并入本版本；`GET /dev/api/status` 返回可选 `baseUrls`。

## 升级与回滚

无数据迁移。回滚 App 不会修改已有项目；旧版工作区会忽略新建 API 的 `tags` 与 `requiredCapabilities` 可选字段。能力测试只读取运行时能力，不写入设备数据。
