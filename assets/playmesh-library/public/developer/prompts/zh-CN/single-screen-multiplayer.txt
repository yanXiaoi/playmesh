【当前显示类型：单屏多人】
main.json 必须分别声明主画面 `orientation` 与控制器 `controllerOrientation`。进入全屏时 SDK/宿主会按当前页面角色请求对应方向；页面仍须使用响应式布局处理浏览器拒绝方向锁定的情况。
capabilities.json 的 `required` 仅供 entries.game 主画面使用，`controllerRequired` 仅供 entries.controller 控制器使用；空数组表示该端没有声明能力，不得回退或合并另一端；两端不得越权使用对方声明的能力。
主机加载 `main.json` 显式声明且真实存在的 `entries.game`，作为公共显示端与 Authority Client；所有玩家加载同样必须显式声明且真实存在的 `entries.controller`。两个入口都不得省略或依赖默认入口。公共显示端不属于 session.players，playmesh.main.player.getCurrent() 必须按 null 处理，不得调用 playmesh.main.player.setNickname()；加入 Session 的控制器 Player 可正常调用。

强制交付：
- entries.game：只负责公共显示、会话展示、Authority 注册和权威消息展示，不提供玩家输入。
- entries.controller：负责玩家输入，通过 submitAction 或 submitState 提交业务意图，并接收公共同步快照。
- Authority service：通过 playmesh.main.sync 处理控制器输入并更新权威状态；SDK 自动把快照发给公共显示端和玩家。

强制禁止：
- 控制器页面不得导入或注册 Authority service。
- 公共显示端不得假设 player 非空，不得把主机加入 players。
- 不得生成普通多屏“所有设备都运行同一游戏入口”的流程。
- 不得生成单机专用流程。

公共显示端最小结构：

import { startAuthoritySync } from "../service/index.js";
await playmesh.ready;

function showError(error) {
  const message = error instanceof Error ? error.message : String(error);
  const target = document.querySelector("#error");
  if (target) target.textContent = message;
  console.error(error);
}

try {
  if (playmesh.main.session.isAuthority()) {
    startAuthoritySync();
  }
} catch (error) {
  showError(error);
}
playmesh.main.session.onStateChange(renderSession);
playmesh.main.sync.observe((snapshot) => render(snapshot.state));

控制器最小结构：

await playmesh.ready;
function showError(error) {
  const message = error instanceof Error ? error.message : String(error);
  const target = document.querySelector("#error");
  if (target) target.textContent = message;
  console.error(error);
}
document.querySelector("#action").addEventListener("click", async () => {
  try {
    await playmesh.main.sync.submitAction({ type: "state.increment" });
  } catch (error) {
    showError(error);
  }
});
playmesh.main.sync.observe((snapshot) => render(snapshot.state));

单屏多人将玩家交互放在 entries.controller，公共显示端展示会话与公共状态。控制器通过 submitAction 提交准备等一次性意图，Authority 使用 onInput 处理；需要按时间推进倒计时或实时规则时配置 onTick。Authority 在满足当前游戏定义的开局条件后调用 playmesh.main.session.start()，并处理该请求的成功或错误结果。
